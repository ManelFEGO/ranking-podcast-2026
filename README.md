# Ranking Podcast 2026 — copia independiente

Esta carpeta contiene una versión estática y autónoma de la página de candidaturas.

## Publicación en GitHub Pages
1. Crea un repositorio público, por ejemplo: `ranking-podcast-2026`.
2. Sube `index.html`, `favicon.svg` y `.nojekyll` a la raíz del repositorio.
3. En el repositorio: **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Branch: `main`; carpeta: `/ (root)`; pulsa **Save**.
6. GitHub publicará la web en una dirección similar a:
   `https://TU-USUARIO.github.io/ranking-podcast-2026/`

## Antes de publicar
El botón **¡Quiero votar!** ya apunta al formulario de Tally que utiliza actualmente la página original.
